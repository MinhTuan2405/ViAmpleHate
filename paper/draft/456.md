# 4. Methodology

This study formulates Vietnamese hate speech detection as a binary classification task. Given an input comment `x`, the model predicts either `NON-HATE` or `HATE`. The proposed model, ViAmpleHate_PhoBERT, is developed from AmpleHate but adapts its target-aware mechanism to Vietnamese social media text.

The input comment is first normalized to reduce noise such as teencode, repeated characters, URLs, emojis, and informal spelling. The normalized text is then word-segmented and encoded by PhoBERT:

```text
H = PhoBERT(x) = [h_0, h_1, ..., h_n]
```

where `h_0` is the `[CLS]` representation and `h_i` is the contextual representation of token `i`.

ViAmpleHate extracts two types of linguistic signals. The first is the target signal, which identifies possible people, groups, or entities being discussed. This is obtained from Vietnamese NER and a Vietnamese target cue bank. The second is the attack signal, which captures hostile predicates, insults, threats, or negative evaluations. These signals are represented as two token index sets:

```text
T_x = M_NER(x) union M_target(x)
A_x = M_attack(x)
```

where `T_x` is the target index set and `A_x` is the attack index set. If no target or attack cue is found, the model falls back to the `[CLS]` token.

The model then builds three relation vectors:

```text
r_exp = HeadAttn(h_0, H[T_x])
r_imp = HeadAttn(h_0, h_0)
r_atk = HeadAttn(h_0, H[A_x])
```

These represent explicit target information, implicit sentence context, and attack information. Each HeadAttention module is computed as:

```text
Q = W_q h_0
K = W_k E
V = W_v E
alpha = softmax(QK^T / sqrt(d))
r = alpha V
```

The three relation vectors are fused into one relation representation:

```text
r = W_r [r_exp ; r_imp ; r_atk] + b_r
```

Instead of using the fixed injection weight in the original AmpleHate model, ViAmpleHate uses an instance-adaptive gate:

```text
g = sigmoid(W_g [h_0 ; r] + b_g)
z = h_0 + g * r
```

The final representation `z` is passed through dropout and a linear classifier to predict the label. This design allows the model to decide how much target-attack information should influence each input.

# 5. Experiments

The experiments mainly compare ViAmpleHate_PhoBERT with the direct AmpleHate_PhoBERT baseline. Both models use the same PhoBERT encoder, so the comparison focuses on the proposed Vietnamese-specific improvements rather than a change in the backbone model.

The baseline follows the original AmpleHate design. It uses English NER to extract target indices `T`, computes a single target relation, and injects it into `[CLS]` with a fixed scalar:

```text
r_base = HeadAttn(h_0, H[T])
z_base = h_0 + e * r_base
```

This baseline is limited for Vietnamese because English NER rarely detects valid Vietnamese targets. As a result, many comments fall back to `T = {0}`, making the model close to a standard PhoBERT classifier.

ViAmpleHate improves this baseline in six concrete ways. First, it replaces English NER with Vietnamese NER. Second, it adds a Vietnamese target cue bank to detect informal target mentions that are not named entities. Third, it introduces a separate attack cue bank to model hostile expressions. Fourth, it replaces the single attention module with relation-bank attention over target, implicit context, and attack signals. Fifth, it uses batched attention so that each sample attends only to its own cue tokens:

```text
scores = bmm(Q, K^T) / sqrt(d)
```

This avoids cross-sample attention inside a mini-batch. Sixth, it replaces the fixed scalar injection with the adaptive gate `g`, allowing relation information to be injected differently for each comment.

For training, the proposed model uses weighted cross-entropy and contrastive loss:

```text
L = L_CE + alpha * L_CL
```

Weighted cross-entropy handles class imbalance, while contrastive loss improves representation separation between `NON-HATE` and `HATE`. The final decision threshold is selected on the validation set by maximizing macro-F1:

```text
t* = argmax_t MacroF1(y, 1[p_HATE >= t])
```

Macro-F1 and HATE-class F1 are used as the main evaluation metrics because they better reflect performance on imbalanced hate speech detection than accuracy.

# 6. Result Analysis or Error Analysis

## 6.1 Experimental Results

The results show that Vietnamese-aware target and attack modeling improves the direct AmpleHate transfer. The baseline already benefits from PhoBERT and target-aware attention, but its target extraction is not suitable for Vietnamese. Because most Vietnamese targets are missed by English NER, the baseline often relies only on the `[CLS]` fallback.

ViAmpleHate addresses this problem by increasing target coverage through Vietnamese NER and target cue matching. It also adds attack cue modeling, which helps the model capture whether a detected target is being evaluated or attacked. The relation-bank design further allows the model to combine three complementary signals: who is being targeted, what hostile expression is present, and what the whole sentence means.

The main improvements are expected in macro-F1 and HATE-class F1. These metrics are more important than accuracy because hate speech datasets are usually imbalanced. A model can obtain high accuracy by predicting many `NON-HATE` samples correctly, but this does not guarantee that it detects hate speech well. Therefore, improvements in HATE-F1 provide stronger evidence that the proposed model better captures the minority hate class.

## 6.2 Error Analysis

Several error types remain. First, offensive but non-hate comments may be misclassified as `HATE` because they contain insults or profanity without a clear group-directed target. Second, implicit hate speech remains difficult because it may rely on sarcasm, stereotypes, or social context rather than explicit target or attack words.

Third, target cues can be ambiguous. Vietnamese pronouns and group nouns may appear in both hateful and non-hateful comments, so detecting a target cue does not always imply hate speech. Fourth, the attack cue bank cannot cover every slang form, spelling variant, or newly emerging offensive expression in Vietnamese social media. Missing these cues may lead to false negatives.

Finally, tokenization and span alignment can introduce errors because Vietnamese NER, word segmentation, and PhoBERT subword tokenization may not always align perfectly. Future work should expand the target and attack cue banks, save per-instance prediction logs, and analyze false positives and false negatives by cue coverage, gate value, and prediction confidence.
